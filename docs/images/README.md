# 实机展示素材

[返回首页](../../README.md)

三张截图均于 2026-10-03 从实际运行的 [Nextgen eVTOL Demo](https://hexing-ai.github.io/nextgen-evtol/) 获取，展示当前三维原型，不是 AI 生成的设计效果图。

| 文件 | 内容 |
| --- | --- |
| `boarding.png` | 中环海滨登机界面与 NG-01 概念机型 |
| `passenger.png` | 乘客舷窗观景与可见地标标签 |
| `pilot.png` | 轻驾驶仪表、外部跟随机位与自动接回入口 |

画面中的城市由 OSM 派生建筑与 Mapzen 地形构建，背景影像来自运行时的 Esri World Imagery。飞机、平台与地标采用概念或简化模型。截图保留完整画面；有无地表影像和其清晰度受加载状态影响。
