# 前端与发布验收记录

日期：2026-10-03。用户已确认视觉方向后实施。

## 已完成

- React / Resium / Cesium 实时三维场景、登机入口、乘客和轻驾驶模式。
- 三种独立镜头、拖动环顾、镜头回正、暂停、自动接回与本机恢复。
- 原创 NG-01 六旋翼 glTF 模型、概念平台、简化地标。
- 7,748 个 OSM 建筑与分层几何对象；真实区域 DEM；在线卫星影像。
- 浏览器键盘实测：从约 14 m 上升至 19 m；加速并转向至约 34°；位置与速度相应变化。
- 浏览器实测拍照成功，本机 IndexedDB 相册显示 1 张图；暂停存档保留位置、模式、镜头与进度。
- 自动接回后到达 05:30 的完整航程终点状态；恢复航程时保持暂停。
- 390 × 844 视口检查：文档宽度 390，无横向溢出，登机按钮位于视口内。
- `npm run check` 通过：27 项自动化测试，0 失败；包含 API、连续航程、模式交接、地形山脊保护；生产构建与静态接口导出成功。
- 安装后移除了引入间接漏洞的非必要静态复制插件，改用 Node 文件系统复制。依赖审计结果为 0 vulnerabilities（安装 pngjs 后记录）。

## 实机发现并修复

- Resium 视图未就绪时初始化，以及不稳定配置对象引发的重建问题。
- Cesium 材质参数超出允许范围导致的渲染中止。
- 地图组件隐藏的署名弹窗被误判为活动对话框，导致键盘输入被挡。
- 原始近景机型过小、远处 H 标识悬浮、窄屏主视角遮挡问题。
- 地图影像加载阻塞入口；改为后台加载，并等本地城市几何准备好再开放登机。

## 尚有限制

- 首版为开放数据构建的三维原型。画质低于离线生成的概念效果图；缺少官方带纹理的精细建筑与专业座舱模型。
- DEM 和 OSM 并非统一测绘基准；部分高度估算，建筑关系和数据覆盖不完整。游戏保护不是航空级安全验证。
- 浏览器测试在本机 Ego Lite 完成；移动端为视口模拟，未实测所有手机 GPU。未承诺跨设备固定帧率。
- Cesium 引擎包较大（约 4.62 MB 原始 / 1.27 MB gzip）；首载速度取决于网络。地图影像服务和在线字体存在外部可用性依赖。
- 正式网站发布与云端 Actions 结果需要在推送后单独确认。
